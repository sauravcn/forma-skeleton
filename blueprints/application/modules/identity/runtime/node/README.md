# Owned password and mandatory TOTP runtime

This source profile is fixed to `auth: {mode:"password",providers:[],twoFactor:true}`. It is not password-only and does not provide social sign-in, a seller identity service or production hosting. Required identity/domain source is physically included in this child. The application composition supplies records permissions from `backend-auth/policy.mjs`; identity core contains no records role map.

Configure explicit `FORMA_IDENTITY_DATABASE_URL`, `FORMA_AUTH_SECRET` (random, at least 32 characters), `FORMA_ORGANIZATION_ID`, `FORMA_PUBLIC_ORIGIN` (an exact loopback HTTP origin with a port), `DATABASE_PATH` (domain SQLite) and distinct `API_PORT` (default 8765). `PYTHON_BIN` defaults to python3. Local `.env` is optionally loaded by command entrypoints, must be ignored by Git and never belongs in a source delivery. No missing database target falls back to ambient PG variables. Use new isolated stores; existing unmarked/populated stores are refused and never assigned to the first signup.

Run `npm run migrate` before start. This explicitly binds each store to app/organization/profile, journals immutable migration checksums and refuses missing/modified applied source. Runtime checks readiness and source history without DDL. The PostgreSQL connection schema/search path is public; a fresh store containing foreign tables, views, materialized views, sequences or functions is refused. Pending/foreign stores cannot start. Keep applied SQL and engine descriptors immutable; add reviewed migrations for changes. No customer data adoption/reset workflow is supplied.

Normal `npm start` (or dev command) requires explicit SMTP_HOST/PORT/USER/PASSWORD/FROM and SMTP_SECURE=true. Missing/known placeholder settings are rejected. SMTP uses TLS and no debug logging; configuration is not proof of successful live delivery. Whole email messages live in `mail-messages.en-US.json`, can be replaced with a complete validated catalog and put token URLs only in the recipient body. Accepted email requests are non-assertive, failures notify only a redacted operational observer; durable outbox/retry delivery is not implemented.

Programmatic `migrateApplication({projectRoot,config,env,sendMail,onDeliveryFailure})` then `createApplication` with the same fields permits private synthetic in-memory mail capture. Call `await app.start()` and `await app.close()`. There is no HTTP test-login or token bypass. Each running Node process owns one child application; a second active factory start is refused to prevent cross-project Next environment changes. The factory supervises its own Python service, exact local ports, Node socket handler and Next lifecycle. Exit/partial-start cleanup stops only its own processes and pools.

The actual socket handler rejects ambiguous critical headers, validates exact local Host/peer and strips forwarded-IP claims. Maintained auth/verification/reset and descriptor routes run before Next. Reset query secrets remain transient in the browser and are removed before Next request logging; only a server-derived boolean permits that reset screen. Python record requests carry only required credentials, validated Origin and bounded JSON to fixed local targets. Every protected operation verifies current session/MFA proof, role/org/owner; UI visibility and descriptor stage never grant authority.

A verified new user gets only normal member policy. An operator with this child's explicit store configuration may run `node identity/node/bootstrap-admin.mjs --user-id <existing-id>` after migrations to promote an existing verified member. This is not a public endpoint or first-user promotion; administrator access still requires current MFA proof.

Run `node --test identity/node/test/*.test.mjs` for pure configuration/mail guards; normal package tests/build do not initialize databases. Full installed-package/browser and real isolated PostgreSQL acceptance are separate release checks. These local development controls are not production TLS, proxy trust, live SMTP acceptance, provider acceptance, key rotation or compliance certification.
